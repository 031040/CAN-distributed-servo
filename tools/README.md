# STM32 伺服控制系统 · Python 上位机

实时接收 STM32 串口数据，绘制位置 / 速度 / PWM 曲线，支持在线调整 PID 参数。

## 功能

- 自动查找 CH340 串口
- 实时绘制三条曲线：位置、速度、PWM
- 运行中输入指令，在线修改 PID 参数 / 目标值
- 板端数据格式（每行一条）：`pos,target_pos,speed,target_speed,pwm`

## 环境准备（一次）

```bash
# 1. 安装依赖（只需要跑一次）
pip install -r requirements.txt
```

## 运行

```bash
# 自动查找串口
python main_plot.py

# 指定串口和波特率
python main_plot.py --port COM3 --baud 57600
```

## 运行中可输入的命令

| 指令 | 作用 |
|------|------|
| `pos 500` | 设置目标位置（电机转到 500 停住）|
| `Kp 2.0` | 速度环 Kp |
| `Ki 0.1` | 速度环 Ki |
| `Kd 0` | 速度环 Kd |
| `Kp_pos 0.2` | 位置环 Kp |

> `q` 由上位机本地处理（退出程序），不会发给板子。
> 指令格式要和板端代码里的解析逻辑一致。

## 和硬件配合

1. 板子烧录"上位机数据输出"固件（V5 位置环工程即可）
2. **板端 USART1 波特率必须改成 57600**（CubeMX 里改，9600 太慢会拖慢 PID）
3. CH340 接到电脑，连接 PA9(USART1_TX)、PA10(USART1_RX)、GND
4. 关掉 CCcom（避免占用串口），运行上位机
5. 看到曲线开始滚动 = 通信成功

## 面试用法

- 演示 PID 调参：把 Kp 从 0.5 调到 2.0，实时看到响应变化
- 演示位置跟踪：发 `pos 500`，看电机转到 500 并稳住
- 配合板端代码一起讲：双环控制 + 串口调试 + PC 可视化

## 常见问题

**"打不开串口"**：串口被 CCcom 占用，先关掉。

**曲线不动**：板子没烧数据程序 / 波特率不对 / 数据格式不匹配。

**收到乱码**：波特率不一致，或 CH340 接线松。
